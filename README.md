# JavaScript למתחילים - שיעור 6

מצגת אינטראקטיבית לשיעור JavaScript בנושא תנאים, לולאות, Scope, פונקציות וחיבור HTML ל-JavaScript.

## קישור למצגת

[פתיחת המצגת ב-GitHub Pages](https://alexvsx360.github.io/lesson-6-2026/)

## מטרת השיעור

השיעור מחבר את הכלים המרכזיים של JavaScript לזרימת קוד מלאה:

- קבלת החלטות עם תנאים ולוגיקה בוליאנית.
- חזרה על פעולות עם לולאות.
- חלוקת קוד לפונקציות ברורות.
- הבנה איפה משתנים ופונקציות קיימים בעזרת Scope.
- חיבור JavaScript לאלמנטים של HTML והצגת תוצאות בדף.

## נושאי הלימוד

| נושא | מה לומדים |
| --- | --- |
| תנאים | `if`, `else if`, `else`, `switch`, תנאים מקוננים |
| לוגיקה בוליאנית | `&&`, `||`, `!`, וגם XOR, NAND, NOR, XNOR |
| לולאות | `for`, `while`, `do...while`, `for...of`, `for...in` |
| שליטה בלולאות | `break`, `continue` |
| פונקציות | Function Declaration, Function Expression, Arrow Function |
| ערכים מפונקציות | פרמטרים, ארגומנטים, `return` |
| Scope | Global Scope, Function Scope, Block Scope, Shadowing, Closure בסיסי |
| DOM | `getElementById`, `addEventListener`, `textContent`, `input.value`, `classList` |
| תרגול מסכם | מחשבון HTML + JS, עבודה עם מערכים ואובייקטים |
